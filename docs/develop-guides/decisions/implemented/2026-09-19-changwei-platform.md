# 江擎工程业务工作台

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/changwei_service.py

## 问题

工程人员需要在同一工作台完成五类业务、资料整理、分模块确认与成果归档。通用会话项目与演示智能体缺少工程标段和审核状态。

## 决策

复用 Yuxi 身份、模型、知识库；新增工程业务域。repository 拥有成员可见性与行锁，service 拥有版本前提、人工确认和不可变成果，router 只适配 HTTP。PostgreSQL 保存工程、资料、任务、成果和审计。schema 1 到 2 由 storage-migrator 迁移。

工作台提供监理日志、项管日志、监理月报、项管月报和施工方案审核。资料包含文字定位与分批 PDF OCR；AI 草稿只读取本任务选择且确认的资料片段，更新正文后撤销确认。负责人在全部模块确认后生成 Word；监理日志默认选择工程中最新上传且名称匹配的原版日志模板，只替换填写人、日期和原表字段，保留标题、班次、说明、表格属性与分页。没有兼容模板时才使用基础版式。成果文件名包含任务日期，旧成果字节不随编辑更新。

每个成果以 PostgreSQL 中的不可变字节作为事实 Owner，先提交到任务的“成果版本”列表，再通过 no-follow Workspace API 写入负责人个人空间的 `/outputs/江擎/<工程-标段>/<日期>/`。工程主导航固定提供“成果归档”，个人空间快速访问固定提供“工程成果”，两者都直接进入 `/outputs/江擎`。输出副本使用成果 ID 后缀避免同一 revision 多次生成时互相覆盖。数据库提交失败时不会触碰输出目录；派生副本写入失败时保留可下载的主成果并返回明确提示，不把派生存储故障伪装成成果丢失。

前端主入口围绕工程工作台、工程总览、工程资料、辅助问答和 AI 中台。总览从可见工程的真实任务与资料统计五类业务；原始深度研究等演示角色从助手列表移出，持久记录和历史对话保留。窄屏使用抽屉导航、任务卡片和底部操作栏，异步返回需匹配工程、路由及编辑上下文。

天气服务负责当日实况查询和来源时间；后端先用和风 GeoAPI 把县、市、区名或设备坐标解析成 LocationID，用户界面不要求填写编号或经纬度。手填按钮显式调用查询函数，查询函数只接受并清理字符串，避免浏览器点击事件被误当成 location 提交。网页只在用户点击“自动定位并获取”后请求设备大致位置，失败或拒绝时继续支持手填地名；查询结果只追加为未保存文本。原版 Word 导出把标准天气文本拆到天气、气温、风力、风向四个小格，Markdown 占位内容不会污染成果。实时语音接口负责已鉴权任务模块的 PCM 流转发，云端 Key 留在后端，最终文本进入编辑器并需人工保存。云端密钥缺失会明确报错，不请求麦克风。

Windows 与 Android 客户端连接同一 HTTPS 后端，使用同源导航、正常证书校验和显式设备权限。客户端不包含模型 Key、数据库或 Docker。Docker 独立项目运行服务；本地 BGE 权重通过私有网络容器只读加载，无宿主监听端口。[静态发布网关](2026-09-19-mobile-release-gateway.md)配合已授权公网隧道提供手机直连。

Windows 客户端在进程运行期间持有安装互斥标记。安装器同时在替换前探测已有程序和运行库的写入及删除访问权限，覆盖没有互斥标记的旧版本；探测只打开现有文件，不写入或删除内容。文件被占用或权限不足时，安装提前提示保存草稿并关闭窗口。Windows Restart Manager 在跨会话或权限限制下无法自动关闭应用，因此不能单独依赖它；安装不强制终止用户进程。安装身份、路径和登录数据目录保持连续，验收模式完成记录后自动退出。

## 替代方案

独立重写会重复身份与模型基础。纯聊天提示词不能约束模块确认、并发版本和成果归档。原生重写每端业务界面会维护多套逻辑，因此安装客户端复用响应式页面。CPU 本地向量服务复用已有权重，避免依赖当前余额不足的云向量接口。

产品名称为江擎，副标题为水利工程智能协作，网页与两端安装客户端共享闸门和水纹图标。仓库目录使用 jiangqing；现有数据库表、路由、Compose 项目标识及客户端包名保留，保证升级与持久数据连续。

## 后果

业务资料使用关键词窗口与来源位置；独立向量知识库已建立，但业务审查未接入完整规范向量检索。复杂月报台账计算、规范版本适用性、在线 Word 协同与第三方报送仍需开发。数据库内保存有限大小的资料与成果适用于当前试用规模，大规模存储需要单独迁移设计。

语音云识别需配置百炼 Key；当前安装客户端依赖电脑后端和公网隧道在线，手机无需安装私网客户端。客户端采用本地试用签名或无发布者签名，不代表应用商店发布。模型草稿需要工程人员核验。
