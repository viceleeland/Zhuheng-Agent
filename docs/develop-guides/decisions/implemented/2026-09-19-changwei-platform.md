# 江擎工程业务工作台

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/changwei_service.py

## 问题

工程人员需要在同一工作台完成五类业务、资料整理、分模块确认与成果归档。通用会话项目与演示智能体缺少工程标段和审核状态。

## 决策

复用 Yuxi 身份、模型、知识库；新增工程业务域。repository 拥有成员可见性与行锁，service 拥有版本前提、人工确认和不可变成果，router 只适配 HTTP。PostgreSQL 保存工程、资料、任务、成果和审计。schema 1 到 2 由 storage-migrator 迁移。

工作台提供监理日志、项管日志、监理月报、项管月报和施工方案审核。资料包含文字定位与分批 PDF OCR；AI 草稿只读取本任务选择且确认的资料片段，更新正文后撤销确认。负责人在全部模块确认后生成 Word；监理日志支持原版表格模板。旧成果字节不随编辑更新。

前端主入口围绕工程工作台、工程总览、工程资料、辅助问答和 AI 中台。总览从可见工程的真实任务与资料统计五类业务；原始深度研究等演示角色从助手列表移出，持久记录和历史对话保留。窄屏使用抽屉导航、任务卡片和底部操作栏，异步返回需匹配工程、路由及编辑上下文。

天气服务负责当日实况查询和来源时间；前端只追加未保存文本。实时语音接口负责已鉴权任务模块的 PCM 流转发，云端 Key 留在后端，最终文本进入编辑器并需人工保存。云端密钥缺失会明确报错，不请求麦克风。

Windows 与 Android 客户端连接同一 HTTPS 后端，使用同源导航、正常证书校验和显式设备权限。客户端不包含模型 Key、数据库或 Docker。Docker 独立项目运行服务；本地 BGE 权重通过私有网络容器只读加载，无宿主监听端口。Tailscale 提供私网 HTTPS。

## 替代方案

独立重写会重复身份与模型基础。纯聊天提示词不能约束模块确认、并发版本和成果归档。原生重写每端业务界面会维护多套逻辑，因此安装客户端复用响应式页面。CPU 本地向量服务复用已有权重，避免依赖当前余额不足的云向量接口。

产品名称为江擎，副标题为水利工程智能协作，网页与两端安装客户端共享闸门和水纹图标。仓库目录使用 jiangqing；现有数据库表、路由、Compose 项目标识及客户端包名保留，保证升级与持久数据连续。

## 后果

业务资料使用关键词窗口与来源位置；独立向量知识库已建立，但业务审查未接入完整规范向量检索。复杂月报台账计算、规范版本适用性、在线 Word 协同与第三方报送仍需开发。数据库内保存有限大小的资料与成果适用于当前试用规模，大规模存储需要单独迁移设计。

语音云识别需配置百炼 Key；安装客户端依赖电脑后端在线和同一 Tailscale 网络。客户端采用本地试用签名或无发布者签名，不代表应用商店发布。模型草稿需要工程人员核验。

## 验证

- 长委后端 unit 75 项通过，覆盖解析、确认、模板、天气、语音协议和失败路径；真实 HTTP、跨用户 404、旧 revision 409、并发 200/409、成果文件与数据库回读已验证。
- 原始资料样本解析、原版监理模板结构与真实天气 HTTP 已验证；DeepSeek 真实日志整理已回读，三份参考资料九个片段的两次向量检索已对照原始来源。
- 前端 lint、185 项 unit 和 build 通过；总览与编辑上下文回归覆盖工程切换及迟到响应。真实浏览器验证桌面与手机导航、任务编辑及工程统计。
- 真实百炼 ASR 经本机接口和 Tailscale WSS 两条路径验证，各发送约 20 秒合成中文音频；流中收到中间文本与完整最终文本，停止后收到完成事件。另以截去末尾静音的约 18 秒音频主动停止，最后一句在停止后定稿且内容完整。三次测试的任务正文、版本、状态与审计数量保持不变。此证据不替代实体麦克风和现场噪声验收。
- Windows 实际安装、HTTPS 页面导航、卸载和再次安装通过；Android 源码与下载桥边界测试通过，构建产物与验收范围由 clients/android 的构建说明拥有。
- 完整后端 unit 中五个失败已在原始 HEAD 独立复现，属于原有 file_listing_scaling、agent_request_queue 和 tool_service 用例；不宣称全仓测试全绿。
- Not run：Android 实机安装与录音、Windows 真实麦克风及文件对话框、完整规范审查准确率、客户所有 Word 模板的视觉验收。文档站依赖未完整安装，docs build 未执行；没有放宽链接检查。
